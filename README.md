# Mini Kanban Board

Demo Kanban application for exploring the TanStack ecosystem with React,
TypeScript, Tailwind CSS, and MSW.

## Scripts

- `pnpm dev` starts the Vite development server.
- `pnpm build` type-checks and builds the application.
- `pnpm lint` runs ESLint.
- `pnpm check-types` runs TypeScript checks.
- `pnpm check-format` checks Prettier formatting.
